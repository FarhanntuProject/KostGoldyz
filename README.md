# Kost Goldyz (Android, versi Claude)

Ikon aplikasi yang membuka Kost Goldyz & Kontrakan di Claude memakai Chrome.

- Login Google berjalan normal, karena memakai login Claude yang sama dengan di Chrome.
- Data tersimpan di akun Claude dan tersinkron dengan laptop.
- AI pembaca bukti transfer aktif tanpa API key.

Syarat: Google Chrome terpasang di HP, dan sudah login ke claude.ai di Chrome.

## Build APK lewat GitHub
1. Upload semua isi folder ini ke repository GitHub.
2. Tunggu sampai muncul centang hijau di tab **Actions**, lalu download **KostGoldyz-apk** dari bagian **Artifacts**.
